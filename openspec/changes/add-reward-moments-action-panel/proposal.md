# 奖励动态与个人行动区

用户希望将“其他人的真实奖励”与“我现在能获得什么”放在同一区域，帮助用户理解活动并直接参与。

首版设计覆盖签到、充值抽奖、消费奖励及后续同类奖励钱包活动。使用现有钱包、领取和九宫格流程，沿用项目 teal/slate 语义色、系统字体和 Button / Badge / BaseDialog，不引入依赖或修改公共样式。

用户已确认预览并授权合入。现已将个人行动区挂载到用户概览，连接现有领取、签到、抽奖和转入流程，并实现真实入账动态、匿名展示授权及后台独立开关。继续复用原有活动详情、顶栏弹窗和九宫格，临时预览已清理。

动态和个人授权均默认关闭。动态仅向后台指定的用户开放，只展示授权后真实到账且未撤销的近期奖励；开关关闭不影响个人奖励操作。验证范围和待完成的部署后实际登录验收见 `validation.md`。
