## Context

统计已有 total_actual_cost（实际扣费）、total_account_cost（含账号倍率的成本）与按日期查询的模型/分组 API。余额接口 `/v1/usage` 接受 Bearer API Key，可返回钱包 balance 或额度 remaining。

## Decisions

- 利润 = total_actual_cost − total_account_cost，支持负利润；未知值显示破折号，不能伪装成零。
- 总消费、成本、利润集中展示于同一张卡片；利润金额使用橙色、成本金额使用绿色。总请求数和总 Token 各使用独立卡片。财务指标在宽屏并排、窄屏纵向排列。
- 总 Token 达到百万时自动显示 M，达到十亿时显示 B，保留一位小数；不足百万时保留完整数值。
- 运营管理页的时间范围默认选择浏览器本地时区的今天，开始日期与结束日期均为当天。
- `/admin/accounts/operations-balances` 使用已有管理员鉴权和账户资源保护。账号在后端分页加载，凭据不返回前端。
- 规范化域名大小写、默认端口、尾部斜杠和 `/v1`；保留租户路径。每站点优先选择启用且 ID 最小的配置完整账号，仅查询一次，展示关联账号数。
- 上游余额位于统计卡片下方、分布图上方。表格仅展示上游地址、关联账号数、余额、状态和查询时间，不展示查询账号、余额类型或实现说明。统计卡片省略范围与费用说明文字。
- 表格数据默认模糊，通过眼睛按钮切换显示；隐藏时禁止聚焦和操作表内链接，并对辅助技术隐藏数据。显示后上游地址可在新标签页打开，不持久化显示状态。
- 每请求超时 10 秒，最多 4 个并发，整体刷新最多 25 秒；沿用上游地址验证、代理和 TLS 配置，禁用重定向。错误仅返回固定代码。
- 钱包余额优先取 balance，否则取 remaining 并区分 Key 额度、订阅余量。失败和不支持不作为零余额；余额不随历史日期筛选。
- ECharts 按需注册饼图、图例、提示、无障碍和 Canvas 模块。监听容器尺寸、主题、语言、数据与指标变化，卸载释放图表。保留明细表与用户展开查询。
- 运营管理页复制模型与分组分布功能并使用独立 ECharts 组件；使用记录页保留原有 Chart.js 图表、来源切换、独立指标和分组数据请求。
- 请求序号保护日期/来源切换，避免旧响应覆盖新结果。余额请求单独取消，统计失败显式呈现。

## Validation

后端测试覆盖 URL 去重、代表账号、Bearer 凭据、余额响应类型、异常响应及超时/代理。前端测试覆盖金额、日期一致性、响应竞争、独立图表指标、用户明细及资源销毁。运行类型检查、lint、测试和构建，并进行浏览器桌面/移动/暗色检查。
