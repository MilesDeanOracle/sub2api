# 营销活动管理视觉重构

状态：已接入正式签到与消费奖励页面，移除临时样稿入口。

正式入口：`/operations/rewards/checkin`、`/operations/rewards/consumption`。

签到采用七天奖励路径与分栏配置，开关具有滑动过渡，操作后仍须保存。消费采用三档奖励路径、活动标签切换、规则编辑与预算侧栏，完整保留余额查询、来源确认、冲正、复核、审计与发布操作。预览金额跟随表单，实际统计来自接口。

样式仅影响营销活动组件；未修改全局样式与公共基础组件。支持中英文、窄屏、深色与减少动效设置。

字段帮助使用局部 RewardFieldTip。营销活动页头也使用该提示，避免原有提示向上越出窗口：根据气泡实际大小与可用空间选择上下方向，横向约束在窗口内，并随滚动和缩放更新。支持悬停、点击、键盘聚焦、Esc 和外部点击关闭。

验证：正式组件的隔离接口浏览器检查、金额转换与保存失败保留、零门槛、字段校验、发布冻结、提示边缘位置与键盘关闭测试。浏览器检查未写入真实配置。

活动选择不再使用下拉框：无历史活动时仅显示草稿状态，有活动时用名称与状态标签切换；新建入口保持单一。
