# 设计

- Chat Completions 流支持 `delta.reasoning_content`，兼容 `delta.reasoning`；同时存在时以前者为准，避免重复。与 `delta.content` 分别累计。
- 流式解析器在首次非空思考或正文到达时仅触发一次首字回调。元数据、心跳、角色及用量不触发。未返回思考的模型沿用正文首字时间。
- 当前结果和本地历史复用 PelicanReasoningPanel，以原生 details/summary 实现可访问的默认折叠区。现有组件中没有对应的思考文本展示功能；源码预览、复制和管理员上报仍只使用正式输出。
- 历史记录增加可选 reasoningText，兼容旧记录；存储配额计入思考文本，取消或失败时也可保留已收到的思考。
- 上报按钮移到结果工具栏下的独立提示栏，使用高对比颜色。仅可提交且尚未提交时短暂提醒，尊重减少动态效果设置；原有提交去重、禁用与弹窗行为保持。
